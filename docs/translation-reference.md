## Подтверждённое поведение

- `src/server/translation/providers.ts`: адаптеры Google через `google-translate-api-x` (^10.7.3), DeepL и LibreTranslate; настройка `none` отключает перевод.
- `config.ts`: автоматический выбор по настройкам, Google без ключа по умолчанию; тайм-ауты и размеры пакетов.
- `engine.ts`: дедупликация фрагментов, пакетная обработка, сохранение успешных переводов, исходный текст при сбое. После трёх ошибок — пауза 60 секунд. Это ограничитель сбоев одного процесса, а не общая квота.
- `text.ts`, `cache.ts`: SHA-256 от провайдера, языковой пары и текста; кэш PostgreSQL плюс память (4000 элементов, TTL 5 минут). Исходный проект допускает работу без БД; в Wikiteku PostgreSQL обязателен.
- `src/lib/markdown-i18n.ts`: построчная сегментация сохраняет префиксы блоков, обычные ссылки и инлайн-код; блоки с тройными обратными кавычками не переводятся.

## Что требуется для Wikiteku

1. Перевод только по явному запросу опубликованной статьи; серверная проверка доступа, языка, размера, дневных пользовательских и общих квот. Оригинал не изменяется. UI показывает источник машинного перевода и понятный сбой вместо выдачи оригинала за перевод.
2. Кэш документа: ID и ревизия статьи, исходный/целевой язык, провайдер и версия движка. Пользовательские исправления — отдельно от машинного результата и оригинала, с проверкой прав и конфликтов ревизии.
3. Сегментацию нужно расширить для синтаксиса Wikiteku: `[[slug|подпись]]`, таблицы, изображения, вложенные ссылки, ограждения кода разной длины. Не переносить регулярные выражения без тестов сохранности структуры.
4. LibreTranslate-адаптер из референса читает `translations[].text`. Перед переносом проверить реальный контракт выбранного сервера: это нельзя считать доказанно работающей интеграцией.
5. Проверить доступность выбранного сервиса из РФ без VPN, условия использования и фактические лимиты. Локальная копия исходников этого не доказывает. Не отправлять пользовательские тексты в провайдер в рамках диагностики; использовать синтетические строки.

Подключён Google через google-translate-api-x 10.7.3 с серверным пакетным адаптером. PostgreSQL-кэш документа, lease и дневные квоты, отдельные исправления редакторов с контролем версии. Сегментация расширена для вики-ссылок, таблиц, изображений, сбалансированных ссылок и ограждений кода. Результат проходит проверку сохранности разметки; некорректный/неполный ответ не сохраняется. Оригинал никогда не подменяется.

Успешно проверены реальный перевод синтетической статьи и полный сценарий на локальной БД/в браузере. Доступность из РФ без VPN отдельно не подтверждена.
