# Архитектурные решения

## ADR 001 — данные

PostgreSQL — единственный источник данных. Drizzle хранит схему и SQL-миграции. Публичные чтения идут через серверные компоненты, изменения через Server Actions. Счётчики дневных квот обновляются атомарным upsert в PostgreSQL. Это переносимо между обычным Node.js и serverless при настроенном пуле соединений.

## ADR 002 — авторизация

Better Auth хранит пользователей и сессии в той же БД через Drizzle. Права фандома проверяются в серверных сервисах на каждом изменении. Публичная регистрация закрыта до подключения подтверждения почты и антиспама; локальный режим можно явно включить через переменную окружения.

## ADR 003 — редактор и Markdown

В Phase 1 хранится оригинальный Markdown. `@ovelwe/z-md` 1.0.2 парсит заголовки, абзацы, списки, цитаты, код, ссылки и выделение. Его AST не содержит изображений и таблиц, вопреки README; эти возможности требуют доработки библиотеки в следующем согласованном этапе. Ссылки в AST фильтруются по URL-схеме до рендеринга React-элементами.

## ADR 004 — хостинг

Node.js runtime, PostgreSQL URL и отсутствие обязательных внешних браузерных ресурсов сохраняют переносимость. Бесплатное публичное размещение и доступ из РФ требуют отдельной проверки из российской сети и проверки условий тарифов; сейчас это внешний блокер, а не подтверждённая возможность.

На 22 октября 2026: [Vercel Hobby](https://vercel.com/docs/plans/hobby) разрешает личное некоммерческое использование; [Layero Free](https://docs.layero.ru/billing/plans/) отдаёт `noindex, nofollow`; [Neon Free](https://neon.com/blog/neon-free-plan-1-gb-per-project) заявляет 1 ГБ PostgreSQL на проект. Эти данные не доказывают доступность всей цепочки из РФ, а квоты и условия могут измениться.

## ADR 005 — перевод

27 октября изучены исходники локальной копии `C:/Users/ovelwe/Downloads/loxa-rpg-site-main/loxa-rpg-site-main`, предоставленной пользователем. 29 октября подключён Google через google-translate-api-x 10.7.3. Серверный пакетный адаптер отделён от прав, квот и PostgreSQL-кэша документа. Ключ учитывает ревизию и хэш исходника, языки, провайдер и версию движка. Редакторские исправления хранятся отдельно и не заменяют машинную версию. Политика доступа одинаковая для статьи и перевода. Локализация UI независима от машинного перевода. Исследование и ограничения: [translation-reference.md](translation-reference.md).

## ADR 006 — визуальный редактор и темы

Puck редактирует версионированный JSON-документ. Сервер валидирует реестр из 17 блоков и вложенность через Zod. Произвольные HTML, CSS и JavaScript не принимаются. URL изображений — HTTPS, видео — идентификатор YouTube/Vimeo. React-рендер и фильтрация ссылок применяются также к предпросмотру.

`fandom_designs` разделяет черновик и опубликованный документ; `design_versions` хранит историю. Сохранение выполняется транзакционно с проверкой ожидаемой ревизии. `user_themes` хранит личные наборы токенов с квотой 30; права и Origin проверяются в обработчиках API. Публичные страницы читаются на сервере.

Тема платформы и scoped-токены `.fandom-canvas` независимы. Статьи наследуют опубликованную тему фандома; индивидуальные темы статей отложены до Phase 3. Восемь декоративных шрифтов с кириллицей поставляются локально через Fontsource, три системных семейства дополняют подборку. Внешний сервис шрифтов не нужен.
