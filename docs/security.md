# Проверки безопасности перед запуском

Первый проход Phase 5 — 5 ноября 2026. Это проверка транспорта API и отказа в доступе; полный аудит приложения ещё не завершён.

## Исправлено

Обработчики личных тем и оформления фандома/статьи раньше вызывали `request.text()` до проверки размера. Запрос без достоверного Content-Length мог целиком попасть в память. Теперь общий `boundedBody` считает байты UTF-8 при чтении и прекращает поток на превышении: 12 000 байт для темы, 256 000 для макета. Превышение возвращает 413, сломанный JSON — 400. Проверка Origin и авторизация выполняются до чтения тела.

Существующие потоковые лимиты медиа, переводов и жалоб сохранены. Общая ошибка превышения имеет отдельный тип; слишком большой запрос перевода теперь классифицируется как недопустимый ввод, а не недоступность провайдера. Проверки Puck-документов и поля ошибок сохранены.

## Воспроизводимые проверки

- `tests/request.test.ts`: точная граница, кириллица в байтах, отсутствующий/ложный Content-Length, отмена потока, освобождение reader при ошибке, точное совпадение Origin по схеме/хосту/порту.
- `scripts/check-security.mjs`: только localhost; production-заголовки, публичное чтение из PostgreSQL, отсутствие/чужой Origin, анонимные изменения, переходы на вход, закрытая регистрация.
- Необязательный `SMOKE_OWNER_PASSWORD` проверяет вход синтетического владельца, отсутствие прав модератора и отклонение потокового UTF-8/повреждённого JSON на трёх маршрутах оформления. Допустимые изменения не отправляются. Нужны существующие синтетические данные Phase 1 и статья модерации.

5 ноября прошли TypeScript, Biome, 27 тестов, production build через `pnpm build --webpack` и оба HTTP-сценария. Turbopack остановлен после задержки на компиляции без результата; его успешная сборка в этот день не подтверждена. CI использует проверенный webpack-путь.

Полная цепочка миграций 0000–0008 применена к новой отдельной локальной БД `wikiteku_ci_20261105`. Production-сервер на порту 3001 с этой пустой базой прошёл анонимный HTTP-сценарий. Тестовая БД сохранена; рабочая `wikiteku` не очищалась. Основной сервер на 3000 прошёл сценарий с синтетическим владельцем.
